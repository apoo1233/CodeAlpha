# Student Performance – Exploratory Data Analysis

## 1. Project Overview

This project was developed as **Task 2 – Exploratory Data Analysis (EDA)** during my **Data Analytics Internship at CodeAlpha**.

The objective of this project is to analyze a student performance dataset using Python and identify meaningful patterns, relationships, and trends in students' academic performance.

The analysis includes data inspection, data cleaning, descriptive statistics, exploratory analysis, and data visualization.

---

## 2. Objectives

The primary objectives of this project are:

* To understand the structure and characteristics of the dataset.
* To identify and handle missing or inconsistent data.
* To perform descriptive statistical analysis.
* To examine the distribution of student scores.
* To analyze relationships between different variables.
* To visualize important patterns and trends.
* To derive meaningful insights from the data.

## 4. Dataset

The project uses a student performance dataset containing information about students' demographic and educational characteristics along with their academic scores.


## 5. Exploratory Data Analysis

The following analysis was performed as part of the project:

### Data Inspection

* Examined the number of rows and columns.
* Identified column names and data types.
* Generated descriptive statistics.
* Checked for missing values.
* Checked for duplicate records.

### Data Cleaning

The dataset was examined for missing, duplicate, or inconsistent records to ensure that the data was suitable for analysis.

### Statistical Analysis

Descriptive statistics were used to understand the distribution and characteristics of student scores, including:

* Mean
* Median
* Minimum and maximum values
* Standard deviation
* Quartiles

### Data Visualization

Visualizations were created to analyze:

* Distribution of subject scores
* Gender-wise performance
* Test preparation and performance
* Parental education and student performance
* Relationships between mathematics, reading, and writing scores
* Correlation between numerical variables

---

## 6. Key Findings

The exploratory analysis provided the following general observations:

* Mathematics, reading, and writing scores have different distributions.
* Reading and writing scores show a strong positive relationship.
* Test preparation status can be associated with differences in student performance.
* Student performance varies across different demographic and educational categories.
* Correlation analysis helps identify relationships between different subject scores.

The detailed analysis, visualizations, and calculated results are available in the Jupyter Notebook.
